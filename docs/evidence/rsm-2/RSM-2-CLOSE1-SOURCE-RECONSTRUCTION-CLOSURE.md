## 7. Product and Architecture Decisions Carried Forward

RSM-3 and all later milestones inherit the following non-negotiable decisions:

- RetroStage Maker is a focused commercial creator, not a general-purpose engine.
- Babylon.js 9 is the sole renderer/runtime adapter.
- Electron is the desktop editor shell and initial exported-player shell.
- TypeScript is the primary implementation language.
- RetroStage-owned versioned documents are canonical.
- Babylon objects are derived, disposable, and non-canonical.
- Canonical mutation must pass through typed RetroStage command/session authority.
- Preview, PIE, and Export are separate execution contexts.
- Project Save and Runtime Save are separate data models.
- Editor and player are separate applications.
- SQLite may be used only as rebuildable local index/cache state.
- Third-party tools accelerate implementation but do not own product semantics.
- Native cinematic sequencing is core.
- External cinematic interchange is optional and generic.
- No hypothetical companion product is required.
- Marketplace, payment, entitlement, and DLC-commerce systems are outside v0.

RSM-3 may not reopen these decisions without an explicit architecture or product-decision change task.
